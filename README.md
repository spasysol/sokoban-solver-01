A push-optimal Sokoban solver: it splits each level into its rooms off the hallway, solves every room push-optimally with A* over pushes (cheapest box-to-goal assignment as the estimate, dead-square and 2x2-block pruning), and stitches the rooms together with walks through the hallway. Practice score 1,000,000 (every instance at its push optimum P*), against the house baseline plain-astar 1.0.0 at 200,000.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=practice/input MAKEFUN_OUTPUT_DIR=out node main.ts
```
